Troubleshooting

Common Errors & Fixes

Things that go wrong for every beginner — and exactly how to fix them. No Stack Overflow rabbit holes required.

No errors found. Try a different keyword.

My object disappeared!

Viewport

You press a key or click somewhere and your object vanishes from the viewport.

Fixes to try:
  • Press H hides objects — press Alt+H to unhide all hidden objects
  • Check the Outliner — the eye icon next to the object may be turned off. Click it to show.
  • Press A to select all, then Numpad . to zoom to fit all objects in view
  • The object may be on a hidden Collection — click the eye icon next to the collection in the Outliner

Black faces on my model

Modeling

Some faces on your mesh appear black or dark even with lights in the scene.

Fixes to try:
  • Flipped normals — go to Edit Mode, select all (A), then press Shift+N to recalculate normals outward
  • Enable "Backface Culling" overlay to see which faces are flipped — go to Viewport Overlays → Geometry → Backface Culling
  • In Edit Mode, go to Overlay → enable "Face Orientation" — blue = correct, red = flipped

Shortcuts aren't working

Interface

You press G, E, or other shortcuts and nothing happens.

Fixes to try:
  • Hover your mouse over the 3D Viewport first — shortcuts only work in the panel your cursor is over
  • Check you're in the right mode — some shortcuts only work in Edit Mode, others in Object Mode. Press Tab to switch
  • Make sure an object is selected — press A to select all, then try again
  • You may have accidentally clicked into a text field — press Esc then try the shortcut again

Render is completely black

Rendering

You press F12 to render but the result is a completely black image.

Fixes to try:
  • No lights in scene — add a light with Shift+A → Light → Sun or Point
  • Camera is not pointing at your objects — press Numpad 0 to check camera view, then reposition
  • Object may be on a hidden render layer — check the camera icon in the Outliner is enabled
  • Using Cycles with 0 samples — go to Render Properties → Sampling and increase samples to at least 128
  • World background is black with no emission — add an HDRI or set World → Background to a color with strength > 0

Can't select vertices / edges / faces

Modeling

In Edit Mode, clicking on vertices, edges, or faces doesn't select them.

Fixes to try:
  • Make sure you're in the right select mode — press 1 for vertices, 2 for edges, 3 for faces
  • X-Ray mode may be off — press Alt+Z to toggle X-Ray so you can select through the mesh
  • You may be in Object Mode instead of Edit Mode — press Tab to enter Edit Mode
  • The wrong tool may be active — press W to switch to the Select tool

Viewport is zoomed in too close / too far

Viewport

Scrolling zooms but stops before getting close enough, or objects are tiny on screen.

Fixes to try:
  • Select your object and press Numpad . to zoom focus directly onto it
  • Press Home to frame all objects in view
  • Zoom clipping issue — go to Viewport Overlays → Clip Start and set it to a smaller value like 0.01m
  • Enable "Auto Depth" in Preferences → Navigation for smoother zooming near objects

Render is very noisy / grainy

Rendering

The rendered image has lots of grain, dots, or fireflies (bright random pixels).

Fixes to try:
  • Increase render samples — Render Properties → Sampling → Render. Try 256 or 512 for cleaner results
  • Enable Denoising — Render Properties → Denoising → enable "Denoise". Works great for Cycles
  • Fireflies (bright dots) — add a Clamp value under Sampling → Advanced → Clamp Direct/Indirect (try value of 4)
  • Switch to EEVEE for faster, cleaner results if photorealism isn't required

Object moves but origin stays behind

Modeling

After moving or editing, the orange origin dot is in the wrong place — not at the object's center.

Fixes to try:
  • Right-click the object → Set Origin → Origin to Geometry (moves origin to the center of the mesh)
  • Or: Right-click → Set Origin → Origin to Center of Mass
  • If you edited in Edit Mode and moved geometry, the origin stays put. Always use G to move in Object Mode to keep them together
  • Apply transforms with Ctrl+A → All Transforms to reset rotation/scale issues

Animation playback is very slow

Animation

Pressing Space to play the animation results in choppy or very slow playback in the viewport.

Fixes to try:
  • Switch to Solid viewport shading (Z → Solid) — Rendered or Material Preview is slower
  • Go to Playback menu in the Timeline → enable "Sync to Audio" or "Frame Dropping" to keep real-time speed
  • Reduce viewport subdivision on heavy meshes — select object → Properties → Modifier → Subdivision Surface → lower viewport level
  • Hide objects you don't need during playback with H to reduce viewport load

Accidentally split / merged panels

Interface

You dragged a corner and now your workspace is split into unexpected panels — or two panels merged.

Fixes to try:
  • Press Ctrl+Z immediately — Blender tracks layout changes and you can undo them
  • To merge panels: drag from one panel's corner into the other — an arrow appears, release to merge
  • To reset the whole layout: File → Defaults → Load Factory Settings (warning: resets everything)
  • Better: save your layout first with File → Defaults → Save Startup File

Material looks different in render vs viewport

Rendering

Your material looks great in Material Preview but very different when you actually render it.

Fixes to try:
  • Material Preview uses EEVEE with studio lights — if you're rendering with Cycles the result will differ. Switch render engine to match
  • HDRI in viewport doesn't automatically apply to render — add a World HDRI in the Shader Editor's World tab
  • Check if your material has nodes connected properly — a disconnected node won't show in Material Preview but may still affect the render
  • Enable "Scene Lights" and "Scene World" in viewport shading options for a more accurate preview

Mirror modifier not working correctly

Modeling

The Mirror modifier mirrors in the wrong place, or the two halves have a gap or overlap.

Fixes to try:
  • Mirror is relative to the object's Origin — make sure the origin is centered. Right-click → Set Origin → Origin to Geometry first, then reposition
  • Apply scale before using Mirror — press Ctrl+A → Scale in Object Mode
  • Enable "Clipping" in Mirror modifier settings to prevent the two halves separating at the center seam
  • Make sure you deleted half the mesh before applying the modifier — Mirror duplicates what you have
