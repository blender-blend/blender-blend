# BlendBridge — Blender Learning Made Simple

**BlendBridge** is a beginner-friendly web-based learning platform designed to help users understand Blender 3D modelling through simple explanations, reference materials, tutorials, and hands-on practice.

The name represents a bridge between beginners and their journey into 3D design.

## Project Overview

Blender is a powerful 3D creation tool, but its interface and large number of features can feel overwhelming to new users. BlendBridge aims to make learning easier by organizing essential information into clear, accessible learning resources.

## Objectives

- Help beginners understand Blender's interface and basic concepts.
- Provide quick access to commonly used keyboard shortcuts.
- Explain Blender modifiers and terminology.
- Direct learners to useful tutorials.
- Help users identify and solve common beginner errors.
- Introduce structured learning, quizzes, projects, and practice activities.

## Existing Learning Resources

- **Home:** Introduction to Blender and learning resources.
- **Shortcuts:** Keyboard shortcut reference.
- **Modifiers:** Information about Blender modifiers.
- **Tutorials:** Curated learning resources.
- **Glossary:** Definitions of Blender terminology.
- **Errors:** Guidance for common beginner problems.
- **Search:** Searchable learning content.

## Planned Enhancements

The following features are planned for future development:

- **Interactive Quiz:** Multiple-choice questions, answer feedback, and score calculation.
- **Mini Projects:** Step-by-step Blender modelling exercises.
- **Learning Roadmap:** A structured path from beginner to advanced topics.
- **Practice Challenges:** Activities to encourage regular hands-on learning.
- **Progressive Web App (PWA):** Installable app-like access and selected offline functionality.

These enhancements will be marked as completed only after implementation and testing.

The repository contains HTML pages, corresponding CSS stylesheets, and JavaScript resources for the existing website. Additional pages and PWA assets will be added as the project develops.

## Running the Project Locally

1. Clone or download the repository.
2. Open the project folder.
3. Start a local static server in the folder. If Python is installed, run:

   ```bash
   python -m http.server 8000
   ```

4. Open `http://localhost:8000` in your browser.
5. Open `index.html` through the local server to explore the website.

Using a local server is recommended instead of opening HTML files directly, especially when testing browser features.
