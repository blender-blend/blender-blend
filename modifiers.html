Non-destructive editing

Blender Modifiers

Modifiers let you change your mesh without permanently altering it. Add them via the 🔧 wrench icon in the Properties panel. Stack multiple modifiers for complex results.

1 Select your object in Object Mode
→
2 Click the 🔧 wrench icon in Properties panel
→
3 Click Add Modifier and choose one
→
4 Adjust settings — changes are non-destructive

Generate Modifiers

Add new geometry to your mesh — copies, edges, thickness, smoothness. They change the shape and topology of the object.

Array

Generate

What it does: Creates multiple copies of your object arranged in a line, grid, or along a path. Great for fences, stairs, chains, brick walls.

How to use: Add modifier → Array. Set Count for number of copies. Use Relative Offset to space them based on object size, or Constant Offset for a fixed gap. Combine with a Curve modifier to array along a path.

Shift+A
Add modifier (in Properties panel)
Ctrl+A
Apply modifier (click it first to select)
💡 Combine Array + Curve modifier to wrap copies around a circular path — perfect for chains or necklaces.

Bevel

Generate

What it does: Rounds off sharp edges by adding extra geometry. Makes models look more realistic — real objects don't have perfectly sharp edges.

How to use: Add modifier → Bevel. Increase Amount to widen the bevel. Increase Segments to make it smoother. Use Limit Method → Angle to only bevel edges sharper than a threshold.

Ctrl+B
Manual bevel in Edit Mode (scroll to add segments)
V
Toggle vertex bevel (after pressing Ctrl+B)
Ctrl+A
Apply the Bevel modifier
💡 Use the modifier version (not Ctrl+B) so you can adjust it later without permanently changing the mesh.

Boolean

Generate

What it does: Combines two meshes using logic — Union (merge), Difference (cut one from another), or Intersect (keep only overlap). Perfect for cutting holes.

How to use: Select your main object. Add modifier → Boolean. Set operation to Difference. Pick a cutter object in the Object field. Hide the cutter with H. Apply the modifier. Delete the cutter object.

H
Hide cutter object after applying boolean
Ctrl+A
Apply the Boolean modifier
X
Delete the cutter object after applying
💡 Enable "Fast" solver in Boolean settings for simple shapes — it's much faster than the default "Exact" solver.

Mirror

Generate

What it does: Mirrors your mesh across an axis (X, Y, or Z). Model one half and get the other half for free. Essential for character modeling and symmetrical objects.

How to use: Add modifier → Mirror. Choose axis (X is default). Enable Clipping to prevent vertices from crossing the center. Work in Edit Mode on one side — the other updates live.

Ctrl+A
Apply mirror (do this last, after modeling)
Tab
Enter Edit Mode to work on one half
G→X
Move on X axis — see both halves update live
💡 Always enable "Clipping" — it locks vertices at the center seam so the two halves stay perfectly joined.

Subdivision Surface

Generate

What it does: Smooths your mesh by subdividing (splitting) faces into smaller faces. Turns a blocky low-poly model into a smooth, organic shape.

How to use: Add modifier → Subdivision Surface. Increase Levels Viewport for smoother preview (2 is usually enough). Keep Render higher (3-4) for final render. Use Catmull-Clark for smooth surfaces.

Ctrl+1
Add Subdivision Surface at Level 1
Ctrl+2
Add Subdivision Surface at Level 2
Ctrl+3
Add Subdivision Surface at Level 3
Ctrl+R
Add loop cuts to control where subdivision smooths
💡 Add loop cuts (Ctrl+R) near edges you want to stay sharp — subdivision smooths everything, loop cuts give you control.

Solidify

Generate

What it does: Adds thickness to a flat or thin mesh. Turns a paper-thin surface into a solid object with actual depth. Perfect for walls, cloth, glass, shells.

How to use: Add modifier → Solidify. Adjust Thickness to control depth. Enable Even Thickness for consistent depth on curved surfaces. Offset controls which direction thickness grows.

Alt+S
Scale along normals (similar effect in Edit Mode)
Ctrl+A
Apply the Solidify modifier
💡 Great for architectural walls — model just the floor plan as a flat mesh, then use Solidify to give it height.

Screw

Generate

What it does: Spins a profile curve around an axis to create a screw, spring, spiral staircase, or vase shape. Works on simple 2D profiles.

How to use: Create a 2D profile (e.g. half of a vase shape) as a mesh. Add modifier → Screw. Set Angle to 360° for a full revolution. Adjust Screw value to add a helical twist. Increase Steps for smoothness.

Numpad 1
Front view — best view to model your profile
Ctrl+A
Apply the Screw modifier
💡 Model your profile in Front view (Numpad 1) with vertices only on one side of the Y axis for best results.

Build

Generate

What it does: Makes the mesh appear face by face over time — like building a structure from scratch in an animation. Each face appears one at a time in order.

How to use: Add modifier → Build. Set Start Frame (when building begins) and Length (how many frames the build takes). Enable Randomize to make faces appear in random order instead of sequential.

Space
Play animation to preview the build effect
Ctrl+A
Apply the Build modifier
💡 Use Build modifier with a Triangulate modifier above it in the stack for consistent results.

Edge Split

Generate

What it does: Splits edges based on angle or sharp marks, creating hard edges on a smooth mesh. Used to create sharp creases without adding extra geometry.

How to use: Add modifier → Edge Split. Use Edge Angle to auto-split edges sharper than a threshold. Or mark specific edges as Sharp in Edit Mode (Shift+E → Sharp) and enable Sharp Edges option.

Shift+E
Mark edge as Sharp in Edit Mode
Ctrl+A
Apply the Edge Split modifier
💡 Edge Split + Subdivision Surface is a classic combo — use sharp marks to control where subdivision stays crisp.

Mask

Generate

What it does: Hides parts of a mesh using a vertex group or an armature bone. The hidden geometry still exists but is invisible in the viewport and render.

How to use: In Edit Mode, select vertices and assign them to a vertex group. Add modifier → Mask. Set Mode to Vertex Group and pick the group. Enable Invert to show the opposite selection.

Ctrl+G
Assign selected vertices to a vertex group
Ctrl+A
Apply the Mask modifier
💡 Animate the vertex group weights to make parts of a mesh appear or disappear over time.

Multiresolution

Generate

What it does: Like Subdivision Surface but stores sculpted detail at each level. Lets you sculpt high-resolution detail while keeping a low-res base mesh. Used in sculpting workflows.

How to use: Add modifier → Multiresolution. Click Subdivide to add levels. Switch to Sculpt Mode and sculpt detail at the highest level. Switch to lower levels to edit the base shape. Use Reshape to bake sculpt detail.

Page Up
Increase subdivision level in Sculpt Mode
Page Down
Decrease subdivision level in Sculpt Mode
Ctrl+A
Apply the Multiresolution modifier
💡 Use Multiresolution for character sculpting — sculpt skin pores and wrinkles at level 6 while keeping a clean level 2 mesh for rigging.

Remesh

Generate

What it does: Rebuilds the mesh topology from scratch — replaces the existing geometry with a clean, uniform grid of quads or voxels. Great for cleaning up messy boolean results.

How to use: Add modifier → Remesh. Choose Voxel mode for sculpting (adjust Voxel Size — smaller = more detail). Or use Quad mode for cleaner topology. Smooth mode gives organic shapes. Higher octree depth = more detail.

Ctrl+R
Voxel Remesh shortcut (in Sculpt Mode header)
Ctrl+A
Apply the Remesh modifier
💡 Apply Boolean first, then use Remesh to clean up the messy topology that Booleans often create.

Skin

Generate

What it does: Creates a skin mesh around a network of edges and vertices — like wrapping skin over a skeleton. Start with just vertices and edges, and Skin builds the 3D surface automatically.

How to use: Start with a single vertex. Extrude vertices (E) to create branches. Add modifier → Skin. Scale vertices (Ctrl+A in Edit Mode) to control skin thickness at each point. Combine with Subdivision Surface to smooth the result.

Ctrl+A
Scale skin radius in Edit Mode (not apply)
E
Extrude vertices to grow the skeleton
Ctrl+A
Apply modifier when done
💡 Mark a vertex as the root with Skin → Mark Root so Blender knows where the skeleton starts — important for rigging.

Triangulate

Generate

What it does: Converts all quads and n-gons in the mesh into triangles. Required for game engines, certain exporters (FBX/OBJ), and physics simulations that need triangle-only meshes.

How to use: Add modifier → Triangulate. Choose Quad Method (how to split quads) — Beauty gives the best-looking result. N-gon Method controls how polygons with 5+ sides are handled. Usually applied before export.

Ctrl+T
Triangulate selected faces in Edit Mode
Ctrl+A
Apply the Triangulate modifier
💡 Keep Triangulate at the bottom of your modifier stack and apply it only when exporting — it removes flexibility for further editing.

Weld

Generate

What it does: Merges vertices that are within a specified distance of each other. Fixes duplicate vertices from imports, boolean operations, or copy-paste workflows without going into Edit Mode.

How to use: Add modifier → Weld. Set the Distance threshold — vertices closer than this are merged. Enable Only Loose Edges to weld only disconnected parts. Perfect for cleaning imported meshes.

M
Merge vertices manually in Edit Mode
Alt+M
Merge by distance in Edit Mode (same concept)
Ctrl+A
Apply the Weld modifier
💡 Place Weld after a Mirror modifier in the stack to automatically merge the center seam vertices.

Wireframe

Generate

What it does: Converts all edges of the mesh into tubes/pipes — turns your solid mesh into a wireframe structure you can render. Great for stylized renders and sci-fi designs.

How to use: Add modifier → Wireframe. Adjust Thickness to control tube width. Enable Even Thickness for uniform tube width on curved surfaces. Enable Replace Original to hide the solid mesh. Add a material to the tubes.

Alt+Z
Toggle wireframe view in viewport (different from modifier)
Ctrl+A
Apply the Wireframe modifier
💡 Combine Wireframe modifier with a Subdivision Surface above it — more geometry = thinner, denser, more detailed wireframe tubes.

Deform Modifiers

Change the shape of your mesh without adding or removing geometry. They bend, twist, stretch, and warp the existing mesh.

Armature

Deform

What it does: Deforms a mesh using an armature (skeleton). This is how character animation works — bones move the mesh. Added automatically when you parent a mesh to an armature.

How to use: Create an Armature. Select your mesh, then Shift+click the armature. Press Ctrl+P → Armature Deform with Automatic Weights. Blender assigns which bones affect which vertices automatically.

Ctrl+P
Parent mesh to armature (Armature Deform)
Alt+P
Clear parent (removes armature connection)
Ctrl+Tab
Switch to Pose Mode on armature to animate
💡 After parenting, go to Weight Paint mode to fix which bones influence which parts of the mesh.

Curve

Deform

What it does: Bends a mesh to follow the shape of a Bezier or NURBS curve object. Great for roads, pipes, cables, and text on a path.

How to use: Add a Curve object (Shift+A → Curve). Select your mesh. Add modifier → Curve. Set the Curve Object field to your curve. Edit the curve shape — the mesh follows it live.

Shift+A
Add a Curve object to the scene
Tab
Enter Edit Mode on the curve to reshape it
G
Move control points to reshape the curve path
💡 Combine Array + Curve modifiers — the Array copies your mesh, and Curve makes those copies follow the curve path.

Lattice

Deform

What it does: Uses a cage (lattice) of control points to deform a mesh. Like squeezing clay inside a box — move the box corners and the mesh inside bends with it.

How to use: Add a Lattice object (Shift+A → Lattice). Scale it to surround your mesh. Select your mesh. Add modifier → Lattice. Set Object to the lattice. Edit the lattice in Edit Mode to deform the mesh.

Shift+A
Add Lattice to scene
Tab
Enter Edit Mode on lattice to move control points
S
Scale the lattice to fit your mesh
💡 Lattice is non-destructive — increase lattice resolution (U, V, W in properties) for more control points.

Simple Deform

Deform

What it does: Four simple deformation types — Twist (spin), Bend (curve), Taper (narrow one end), Stretch (elongate). Quick way to deform shapes without manual editing.

How to use: Add modifier → Simple Deform. Choose mode: Twist, Bend, Taper, or Stretch. Adjust the Angle or Factor. The axis determines direction. Use Limits to affect only part of the mesh.

R→X/Y/Z
Rotate on axis — works similarly to Twist mode
Ctrl+A
Apply the Simple Deform modifier
💡 Stack two Simple Deform modifiers — first Bend 360° to make a ring, then Bend again to turn the ring into a torus shape.

Shrinkwrap

Deform

What it does: Projects one mesh onto the surface of another — like shrink-wrapping plastic around an object. Used for retopology, decals, and snapping mesh to a surface.

How to use: Select the mesh you want to project. Add modifier → Shrinkwrap. Set the Target to the surface mesh. Choose wrap method: Nearest Surface Point for most uses. Adjust Offset to sit slightly above the surface.

Shift+Tab
Toggle Snapping (useful alongside Shrinkwrap)
Ctrl+A
Apply the Shrinkwrap modifier
💡 Use Shrinkwrap for retopology — draw clean quad topology over a high-res sculpt by snapping vertices to the surface.

Smooth

Deform

What it does: Smooths the mesh by averaging vertex positions — flattens bumps and rough areas. Unlike Subdivision Surface, it doesn't add new geometry, just repositions existing vertices.

How to use: Add modifier → Smooth. Increase Repeat for more smoothing passes. Adjust Factor (0–1) to control strength. Use a Vertex Group to smooth only specific areas.

Alt+S
Smooth vertices in Sculpt Mode
Shift
Hold while sculpting to temporarily smooth
Ctrl+A
Apply the Smooth modifier
💡 Use Smooth modifier after Boolean operations — Booleans often create messy geometry that benefits from smoothing.

Displace

Deform

What it does: Moves vertices based on a texture — black areas push inward, white areas push outward. Creates surface detail like bumps, terrain, or carved patterns procedurally.

How to use: Add modifier → Displace. Create a new texture (click New in the texture field). Go to the Texture properties tab and set Type to Clouds for organic bumps or Image for a height map. Adjust Strength.

Ctrl+1 to 3
Add subdivision first — Displace needs dense mesh
Ctrl+A
Apply the Displace modifier
💡 Add Subdivision Surface BEFORE Displace in the stack — more geometry = smoother, more detailed displacement result.

Cast

Deform

What it does: Casts (morphs) a mesh toward a sphere, cylinder, or cuboid shape. Blends between the original mesh shape and the target shape using a factor value.

How to use: Add modifier → Cast. Choose Cast Type: Sphere, Cylinder, or Cuboid. Adjust Factor from 0 (original shape) to 1 (fully cast shape). Use a Vertex Group to limit which parts are affected.

I
Insert keyframe on Factor to animate the cast effect
Ctrl+A
Apply the Cast modifier
💡 Animate the Factor value to morph between your original mesh and a sphere — great for blob or morph animations.

Corrective Smooth

Deform

What it does: Smooths mesh deformations caused by armature rigging — specifically fixes the pinching and collapsing that happens at joints like elbows and knees during animation.

How to use: Place BELOW the Armature modifier in the stack. Add modifier → Corrective Smooth. Set Factor and Repeat. Enable Only Smooth to prevent it from affecting the rest position. Use a Vertex Group to limit to problem areas.

Ctrl+Tab
Switch to Pose Mode to test joint deformation
Ctrl+A
Apply the Corrective Smooth modifier
💡 Always place Corrective Smooth AFTER the Armature modifier in the stack — order matters here.

Hook

Deform

What it does: Links selected vertices to an object (usually an Empty) — when the object moves, the hooked vertices follow it. Great for controlling specific parts of a mesh with simple objects.

How to use: In Edit Mode, select the vertices you want to hook. Press Ctrl+H → Hook to New Object. An Empty appears — move it to pull those vertices. You can also hook to a bone.

Ctrl+H
Hook selected vertices to new object or bone
Alt+H
Remove hook from selected vertices
G
Move the Empty to pull hooked vertices
💡 Hook multiple sets of vertices to different Empties for a simple puppet-like rig without a full armature.

Laplacian Deform

Deform

What it does: Deforms a mesh while preserving its surface details. When you move an anchor point, the mesh bends naturally without stretching or distorting fine surface details like wrinkles or skin pores.

How to use: In Edit Mode, assign vertices to a vertex group as anchors. Add modifier → Laplacian Deform. Set the Anchors vertex group. Click Bind. Move anchor vertices in Edit Mode to deform — details are preserved automatically.

Ctrl+G
Assign anchor vertices to a vertex group
G
Move anchor vertices in Edit Mode to pose the mesh
Ctrl+A
Apply the modifier
💡 Works best on dense meshes — the more geometry, the better the surface detail preservation during deformation.

Mesh Deform

Deform

What it does: Uses any closed mesh object as a deformation cage. Move vertices of the cage mesh and the object inside deforms with it — more flexible than Lattice since the cage can be any shape.

How to use: Create a closed mesh cage around your object. Select your object. Add modifier → Mesh Deform. Set Object to the cage mesh. Click Bind (takes a moment). Edit the cage in Edit Mode to deform the inner object.

Tab
Enter Edit Mode on cage to start deforming
G
Move cage vertices to deform the inner mesh
Ctrl+A
Apply the Mesh Deform modifier
💡 Unlike Lattice (box-only), Mesh Deform cage can be any shape — great for deforming a character using a body-shaped cage.

Surface Deform

Deform

What it does: Binds one mesh to the surface of another — the bound mesh follows the deformations of the target. Used in cloth simulations to make accessories like buttons or belts follow a cloth garment.

How to use: Select the object you want to bind (e.g. a button). Add modifier → Surface Deform. Set Target to the controlling surface (e.g. shirt mesh). Click Bind. Now animate the shirt and the button follows automatically.

Space
Play simulation to see Surface Deform in action
Ctrl+A
Apply the Surface Deform modifier
💡 The target surface must completely surround the bound object at bind time — make sure there's no penetration before clicking Bind.

Warp

Deform

What it does: Warps parts of a mesh from one point to another using two objects as "from" and "to" anchors. Pulls vertices toward the target position with a controllable falloff.

How to use: Add two Empty objects — one as "from" and one as "to". Select your mesh. Add modifier → Warp. Set Object From and Object To fields. Adjust Strength and Falloff Type for how widely the warp spreads. Move the Empty objects to control the effect.

Shift+A
Add Empty objects to use as warp anchors
G
Move Empty objects to control warp direction
Ctrl+A
Apply the Warp modifier
💡 Use Empties at strategic positions on a character's face to create subtle warp-based facial expressions as a lightweight alternative to shape keys.

Wave

Deform

What it does: Adds animated ripple or wave motion to a mesh — moves vertices up and down in a wave pattern over time. Quick way to simulate water surface, flags, or vibration without complex simulations.

How to use: Add modifier → Wave. Enable X and/or Y to set wave direction. Adjust Speed, Height (amplitude), and Width (wavelength). Enable Cyclic for continuous looping. Works automatically when you play the animation.

Space
Play animation to see wave motion
Ctrl+1 to 3
Add Subdivision Surface first for smooth waves
Ctrl+A
Apply the Wave modifier
💡 Add a Subdivision Surface modifier BEFORE Wave in the stack — waves need dense geometry to look smooth, not blocky.
