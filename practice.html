3. Mini Projects & Practice Challenges

Short, focused 15–30 minute exercises to practice shortcuts and modifiers without following a long video.

Challenge 01 · Beginner ⏱ 15 mins

Low-Poly Coffee Mug

Create a clean 3D coffee cup from a single cylinder using Edit Mode extrusions and modifiers.

  1. Press Shift+A → Mesh → Cylinder and delete the top face in Edit Mode (3 then X).
  2. Add a Solidify modifier (tick Even Thickness) to give the cup walls.
  3. Add a Loop Cut (Ctrl+R) on the side and extrude (E) two faces out and bridge them to form the handle.
  4. Add a Subdivision Surface modifier (Ctrl+2) and Shade Auto Smooth.
Key Tools Practiced: Shift+A, Tab, E, Ctrl+R, Solidify, Subdivision Surface
Challenge 02 · Beginner ⏱ 20 mins

Sci-Fi Storage Crate

Practice hard-surface modeling on the default cube using Inset, Extrude, and the Bevel modifier.

  1. Select the default Cube, enter Edit Mode (Tab), and press A to select all 6 faces.
  2. Press I twice (Inset Individual Faces) to create a frame on each side of the cube.
  3. Press Alt+E → Extrude Faces Along Normals and push the inner panels slightly inward.
  4. Return to Object Mode, apply Scale (Ctrl+A), and add a Bevel modifier (3 segments).
Key Tools Practiced: I (Individual Inset), Alt+E, Ctrl+A, Bevel Modifier
Challenge 03 · Intermediate ⏱ 25 mins

Symmetrical Robot Head

Model half of a stylized robot character and let the Mirror and Boolean modifiers do the rest.

  1. Add a Cube, cut it down the center (Ctrl+R), delete the left half, and add a Mirror modifier (enable Clipping).
  2. Extrude (E) and scale (S) to shape the helmet visor and ear panels.
  3. Add a small Cylinder, position it over the eye area, and use a Boolean (Difference) modifier to carve out eye sockets.
Key Tools Practiced: Mirror (with Clipping), Boolean (Difference), H to hide cutter
Challenge 04 · Intermediate ⏱ 20 mins

Glowing Crystal Pillar

Combine mesh editing, the Array modifier, and an Emission shader for a glowing render.

  1. Add a Cylinder (6 vertices), grab the top face in Edit Mode, scale it to a point (S), and bevel the edges (Ctrl+B).
  2. Use Shift+D to duplicate and rotate smaller crystals around the base.
  3. In the Shader Editor, assign a Principled BSDF with high Transmission and subtle blue/orange Emission, then press F12.
Key Tools Practiced: Shift+D, Ctrl+B, Shader Editor, Camera View (Numpad 0), F12
