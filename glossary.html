Blender Glossary

Every Blender term explained in plain English — no jargon, no assumptions.

No terms found. Try a different search.
A

Armature

A skeleton made of bones used to animate and deform a mesh. Think of it like a puppet's wire frame — you move the bones, the mesh follows.

Animation
A

Asset

Any reusable item in Blender — a material, object, pose, or world. Assets can be saved to an Asset Library and reused across projects.

General
B

Bevel

Smoothing a sharp edge by replacing it with one or more angled cuts. Real-world objects don't have perfectly sharp edges — beveling makes models look more realistic. Shortcut: Ctrl+B

Modeling
B

Bone

The individual pieces that make up an Armature. Each bone controls part of a mesh when animating. Bones have a head, tail, and can be parented to each other.

Animation
B

Boolean

A modifier that combines two meshes using logic — Union (merge), Difference (cut one from another), or Intersect (keep only overlap). Great for cutting holes in objects.

Modifier
C

Camera

An object that defines what gets rendered. Only what's visible through the camera appears in your final render. Press Numpad 0 to look through the active camera.

Rendering
C

Cycles

Blender's physically accurate render engine. It traces the path of light rays for realistic results, but takes longer to render than EEVEE. Best for high-quality still images.

Rendering
E

Edge

A straight line connecting two vertices. Along with vertices and faces, edges are one of the three basic components of a mesh. Select edges by pressing 2 in Edit Mode.

Modeling
E

EEVEE

Blender's real-time render engine. Much faster than Cycles but less physically accurate. Great for previews, stylized renders, and animations where speed matters.

Rendering
E

Extrude

Pulling out new geometry from a selected face, edge, or vertex. One of the most used tools in modeling — like pulling clay out of a surface. Shortcut: E in Edit Mode.

Modeling
F

Face

A flat polygon formed by connecting 3 or more edges. Faces make up the visible surface of a mesh. A face with 3 vertices is a triangle (Tri), with 4 is a quad, with 5+ is an N-gon.

Modeling
G

Geometry Nodes

A node-based system for procedurally creating and modifying geometry. Instead of modelling by hand, you connect logic nodes to generate shapes, patterns, and effects automatically.

Advanced
K

Keyframe

A snapshot of an object's position, rotation, scale (or other property) at a specific frame in time. Blender interpolates between keyframes to create animation. Press I to insert one.

Animation
M

Material

Defines how the surface of an object looks — its color, roughness, metallicness, transparency, and more. Materials are made using the Shader Editor with nodes.

Shading
M

Mesh

The 3D object made up of vertices, edges, and faces. When you add a cube or sphere in Blender, you're adding a mesh. Most 3D modeling in Blender is mesh modeling.

Modeling
M

Modifier

A non-destructive operation applied on top of your mesh — like Subdivision Surface (smoothing), Mirror, or Array. Modifiers can be turned on/off at any time without losing the original shape.

Modeling
N

Normal

An invisible arrow pointing outward from a face, telling Blender which side is the "outside". If normals point inward, faces can appear black or invisible. Fix with Shift+N in Edit Mode.

Modeling
N

Node

A building block in Blender's node editors (Shader, Geometry, Compositor). Nodes take inputs, do something to them, and produce outputs — like a visual programming system.

Shading
O

Object Mode

The default mode where you work with whole objects — moving, rotating, scaling them as a unit. Contrast with Edit Mode where you edit the shape of the object itself. Switch with Tab.

General
O

Origin

The reference point of an object — shown as an orange dot. Rotation, scaling, and position are all calculated relative to the origin. You can move the origin independently from the mesh.

General
O

Outliner

The panel (top-right by default) that lists every object, collection, and data block in your scene. Use it to select, hide, or organize objects. Think of it as a file explorer for your 3D scene.

Interface
P

Parent / Child

When one object is "parented" to another, it follows the parent's movements. If you move the parent, the child moves too. Use Ctrl+P to parent, Alt+P to clear.

General
R

Render

The process of computing the final image or animation from your 3D scene. Blender calculates lighting, materials, and camera position to produce a 2D output. Press F12 to render.

Rendering
R

Rigging

The process of adding an armature (skeleton) to a mesh and setting up controls so it can be animated. A rigged character can be posed and animated by moving its bones.

Animation
S

Shader

A program (represented as nodes in Blender) that defines how light interacts with a surface. The most common is the Principled BSDF — a one-stop shader for almost any real-world material.

Shading
S

Subdivision Surface

A modifier that smooths a mesh by subdividing its faces. Add it to a blocky low-poly model to make it smooth and organic. More subdivisions = smoother but heavier to render.

Modifier
T

Texture

An image or procedural pattern applied to a 3D surface to add color, bumps, roughness, or other detail. Textures are applied through materials using the Shader Editor.

Shading
T

Transform

The collective term for an object's position (location), rotation, and scale. These three properties define where, how much turned, and how big an object is in the scene.

General
U

UV Map / UV Unwrap

UV unwrapping "unfolds" a 3D mesh into a flat 2D layout so a texture image can be applied accurately. Think of peeling an orange skin flat — the skin is the UV map. Press U in Edit Mode to unwrap.

Texturing
V

Vertex / Vertices

The most basic element of a mesh — a single point in 3D space. Two connected vertices form an edge, three or more form a face. Select vertices in Edit Mode by pressing 1.

Modeling
V

Viewport

The large 3D area where you view and interact with your scene. You can have multiple viewports at once. The viewport shading (Solid, Material, Rendered, Wireframe) is changed with Z.

Interface
W

Weight Paint

A mode for painting influence values onto a mesh — controlling how strongly bones in an armature affect different parts of the mesh. Blue = no influence, Red = full influence.

Animation
W

Workspace

A preset layout of panels optimized for a specific task — like Modeling, Shading, Animation, or Rendering. Switch between workspaces using the tabs at the very top of the Blender window.
