🚀 4-Step First-Launch Setup for Beginners

Do these 4 quick steps the first time you open Blender to avoid common beginner headaches:

Step 01

Install or Extract

Run the installer for Windows (.msi), macOS (.dmg), or Linux — or unzip the Portable .zip version and double-click blender.exe.

Step 02

Quick Setup Screen

On the welcome splash screen, keep Select with: Left and Spacebar: Play (default), then click Save New Settings.

Step 03

Laptop Numpad Fix

No side Numpad on your laptop? Go to Edit → Preferences → Input and tick Emulate Numpad so keys 1–0 switch views.

Step 04

Verify Auto-Save

Go to Edit → Preferences → Save & Load and make sure Auto Save is enabled (2 min timer) so you never lose work.

Beginner tip

Object Mode vs Edit Mode

Edit Mode: Reshaping Vertices, Edges & Faces Official Docs ↗

This confuses every beginner. Object Mode moves whole objects as a unit. Edit Mode lets you reshape individual vertices (1), edges (2), and faces (3). Press Tab to switch.

Tab switch modes  ·  1 / 2 / 3 vertex / edge / face

Beginner Tips

Things the docs don't tell you

Small things that make a huge difference when you're just starting out.

Tip 1 of 8

01

Right-click to cancel

Pressed G, R, or S by accident? Just right-click to cancel the action without changing anything. Way faster than Ctrl+Z.

02

F3 is your best friend

Can't find something in the menus? Press F3 anywhere to search every single command in Blender by name.

03

Numpad controls your view

Numpad 1 = Front, 3 = Right, 7 = Top, 0 = Camera. No numpad? Go to Edit → Preferences → Input → Emulate Numpad.

04

Save often with Ctrl+S

Blender can crash. Save every few minutes. Even better — go to Edit → Preferences → Save & Load and enable Auto Save.

05

X, Y, Z lock your axis

After pressing G, R, or S — press X, Y, or Z to constrain movement to that axis. Press twice (e.g. YY) to use local axis.

06

Hover + shortcut = context

Blender shortcuts only work in the panel your mouse is hovering over. If a shortcut does nothing — move your mouse into the right panel first.
